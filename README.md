# Lap Logger（本庄サーキット用 走行ロガー＆分析）

スマホのブラウザだけで動く、GPS ベースの走行データロガーと分析ツールです。
インストール不要の Web アプリ（PWA）で、ホーム画面に追加すればアプリのように使えます。

- **計測**: GPS（位置・ドップラー速度・方位）＋ 加速度センサーを記録。S/F ラインを越えるたびにラップタイムを表示（前周・ベスト・差）
- **分析**
  - ラップ一覧（タイム、ベストとの差、セクタータイム、理論ベスト、最高速）
  - 走行ラインを地図（航空写真）に表示。速度・前後G（ブレーキ／加速）・横Gで色分けし、ブレーキ開始地点も表示
  - 基準ラップと比較ラップを重ねたグラフ：速度、タイム差（どこで何秒失ったか）、前後G、横G（距離軸、なぞるとカーソルが地図と連動）
  - G-G ダイアグラム（摩擦円）
  - ブレーキングの表（開始位置、進入速度、最低速度、最大減速）。比較ラップが何 m 手前／奥でブレーキしたかも出します
  - コーナーごとの最低速度の比較と、タイム差が大きい区間の自動コメント
- **データ**: 端末内（IndexedDB）に保存し、外部へは送りません。CSV / GPX / JSON で書き出せます
- **読込**: 本アプリの CSV/JSON、GPX、NMEA、緯度・経度・時刻の列を含む一般的な CSV（RaceChrono など他アプリの書き出しや、10Hz 外部 GPS ロガーのデータ）

## 使い方（サーキット当日）

1. スマホで公開 URL（下記）を開き、「ホーム画面に追加」する。一度開けば、電波が弱くてもオフラインで起動できます
2. スマホをホルダーでしっかり固定する（走行中に向きが変わらないようにする）。Gセンサーの向きは走行データから自動で推定するので、どの向きで付けても大丈夫です
3. ピットで「計測」→「記録開始」。位置情報（iPhone は加えて「モーションと画面の向き」）へのアクセスを許可する
4. **記録中はアプリを前面に出したまま、画面を点けたままにする**（自動ロックを防ぐ仕組みを使っていますが、念のため自動ロックをオフにしておくと確実です）
5. 走行後に「記録停止」すると、そのまま分析画面が開きます

### S/F（コントロール）ライン

- 初回はライン未設定です。分析時に、セッションの最高速地点（＝メインストレート）に自動でラインを置き、コースに保存します。**2回目以降の走行では、記録中もラップがリアルタイムに表示されます**
- 正しい位置にしたいときは、分析画面の地図で「S/Fライン設定」を押し、コントロールラインのあたりをタップします
- 「セクター追加」で区切りの地点をタップすると、セクタータイムと理論ベストが出ます

## 精度について

- スマホの GPS は**毎秒1回（1Hz）**程度の更新です。アプリ側で補間と平滑化をしていますが、前後G（特にブレーキのピーク値）は実際より小さめに出ます
  - Gセンサーの向き推定が成功すると、分析画面の「前後・横GにGセンサー値を使う」で、センサーから求めた細かい G を使えます
- 横Gは GPS の方位変化から求めるので、比較的正確です
- より細かく見たいときは、10Hz 以上の外部 GPS（Bluetooth GNSS ロガー等）のデータを「セッション → ファイル読込」から読み込んでください

## 公開方法（GitHub Pages）

位置情報を使うには HTTPS での配信が必要です。

1. このブランチを `main` にマージする
2. GitHub のリポジトリで **Settings → Pages → Build and deployment → Source** を **GitHub Actions** にする
3. `main` に push すると、`.github/workflows/pages.yml` がテストのあと自動で公開します
   URL は `https://<ユーザー名>.github.io/<リポジトリ名>/` です

## 開発

ビルド不要の素の HTML / JavaScript（ES Modules）です。

```
js/core.js    解析（補間・平滑化、G算出、周回検出、ブレーキ/コーナー検出、入出力）※Node でも動く
js/app.js     画面（計測・セッション・分析・設定）
js/chart.js   グラフ（距離軸・ズーム・カーソル同期）、G-G ダイアグラム
js/store.js   保存（IndexedDB / localStorage）
js/demo.js    デモ用の疑似走行データ（架空のコース）
sw.js         オフライン用のキャッシュ
vendor/leaflet 地図ライブラリ（Leaflet 1.9.4, BSD-2-Clause）
```

テスト: `node test/core.test.mjs`（疑似データの 1Hz / 10Hz で周回検出・G 算出・入出力を確認します）

画面の確認には、ローカルの HTTP サーバーで配信してブラウザで開きます（例: `python3 -m http.server`）。「セッション → デモデータ」で分析画面を試せます。
